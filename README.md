## 👋 About

This started as a fun little personal project. I wanted a place where I could quickly check all the Warframe information I care about whenever I jump into the game. Then I thought... **Why not share it with everyone?** Maybe there are other Tenno's out there who want the same kind of heads up as I do. So here it is!

**Warframe Live Dashboard** brings useful Warframe information together in one place, helping you keep track of what's happening across the Origin System. Built for myself, shared with the community. 💙
